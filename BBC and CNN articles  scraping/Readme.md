# BBC and CNN News Articles Web Scraping

## 📌 Project Overview

This project focuses on collecting news articles from **BBC** and **CNN** using **Python Web Scraping** techniques.

A total of **200 news articles** were collected:

- 📰 100 articles from BBC
- 📰 100 articles from CNN

The collected data can be used for further analysis, Natural Language Processing (NLP), Machine Learning, sentiment analysis, text classification, and other research purposes.

---

## 🎯 Project Objectives

The main objectives of this project are:

- To collect news articles automatically from online news websites.
- To extract useful information from BBC and CNN articles.
- To create a structured dataset for further analysis.
- To demonstrate web scraping techniques using Python.
- To prepare textual data for NLP and Machine Learning tasks.

---

## 📊 Dataset Information

The dataset contains articles collected from two major news sources:

| News Source | Number of Articles |
|------------|-------------------|
| BBC        | 100               |
| CNN        | 100               |
| **Total**  | **200**           |

Depending on the scraping process, the dataset may include information such as:

- Article Title
- Article Content
- News Source
- Article URL
- Publication Date
- Category
